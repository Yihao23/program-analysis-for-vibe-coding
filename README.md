# Program Analysis for Vibe Coding

*中文版：[README.zh.md](README.zh.md) · [CONCEPT-MAP.zh.md](CONCEPT-MAP.zh.md) · [WORKFLOW.zh.md](WORKFLOW.zh.md)*

A compact C++ demo (18 files).

The concepts of *Program Analysis* lectures 01–09, turned into a runnable gate aimed specifically at code generated by AI agents.
Theory background: [`docs/ai-code-under-control.md`](docs/ai-code-under-control.md) ([中文](docs/ai-code-under-control.zh.md)). 18 files.

```
cmake -S . -B build -G Ninja && cmake --build build
./build/gate check                        # run the gate on the current code
./build/gate demo                         # six scenarios: install each agent candidate in turn
./build/gate demo 1                       # only scenario 1
./build/gate affected app/core/users.hpp  # worklist: what must be rechecked if this changes
```

Only g++ and CMake are required. clang-tidy is picked up automatically if installed, otherwise marked ○.

organised by lecture 01–09, ending with the three load-bearing formulas and the expanded explanations of `f(γ(m)) ⊑ γ(f#(m))` and `l ⊑ AC(l,u) ∧ u ⋢ AC(l,u)`.

## How to read the report

```
UPPER  constraints — must never        mechanical, can run unattended
LOWER  examples — must be able to      proves it did what was asked
HYPER  hyperproperties — compare two runs

upper ✓ lower ✓ → mergeable
upper ✓ lower ✗ → did not cross a line, but did not do what was asked (wait for review / regenerate)
upper ✗ lower ✓ → did what was asked, but crossed a line (reject, no human needed)   ← the cell that takes the human out of the bottleneck
upper ✗ lower ✗ → reject
```

## Six scenarios (`gate demo`)

| # | Candidate | Caught by | Lecture |
|---|---|---|---|
| 0 | baseline | all pass | this is I |
| 1 | `dedupe` via `std::set` | upper (counterexample `["abb", "a"]`) | 07 the minimal program when only a lower bound is given |
| 2 | `dedupe` + an equivalent `unique` | reduce | 05 redundant representation = rot |
| 3 | features `#include` billing and change global rounding | arch | 03 an unwritten convention does not exist for an AI |
| 4 | features change global rounding via a forward declaration | noninterf (arch is blind) | 09 implicit flow |
| 5 | `update_user` forgets to invalidate | lower (cross-file test) | 07 composition ≠ best of the composition |

`gate demo` restores the files when done. To see it with your own eyes: `cp candidates/dedupe_set.hpp app/features/dedupe.hpp && ./build/gate check app/features/dedupe.hpp`, then restore with git or by hand.
